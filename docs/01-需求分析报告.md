# 01 需求分析报告

> 项目：敲敲救——基于多模态识别的 AI 应急响应与救护员调度平台
> 版本：v0.1（中期版）　日期：2026-11　依据：《居家老人应急求助需求与意愿调查》问卷（N=141）

## 1. 背景与目标

老龄化背景下，居家老人突发意外（跌倒、胸闷、眩晕等）时普遍面临"不会操作手机、说不清情况、身边无人"的三重困境；同时大量持证救护员缺乏参与社会急救的渠道，供需之间存在信息孤岛。

本项目目标：

1. 为老人提供"简单操作即可求助"的 AI 应急入口（敲击触发 + 语音收集）；
2. 实现持证救护员的分级、就近调度，填补 120 到达前的响应空白；
3. 构建"AI 前置响应 + 社会急救力量"的两级响应模式。

## 2. 调研方法与样本

- 方式：问卷星线上问卷《居家老人应急求助需求与意愿调查》，共 24 题；
- 回收：有效问卷 **141 份**（远超申报书计划的 50 份样本量）；
- 样本画像：95.74% 由家属代答（子女 69.5%、孙辈 20.6%）；老人年龄 70-79 岁占 55.3%、80 岁及以上占 23.4%（合计 78.7%）；独居老人家庭占 20.6%；与配偶同住 39.0%、与子女同住 36.9%。

> 样本结构说明：以家属视角为主，符合"老人本人难以自行填答"的现实；独居与高龄占比足以支撑应急场景分析。

## 3. 核心发现

### 3.1 突发状况高频发生，现有应对依赖家属

| 发现 | 数据 |
| --- | --- |
| 曾遇到突发意外（摔倒、胸闷、眩晕等） | **63.1%**（偶尔 58.9% + 较多次 4.3%） |
| 应对方式（多选）：自己/家属赶过去处理 | **75.2%** |
| 应对方式：拨打 120 | 53.2% |
| 应对方式：联系邻居或社区物业 | 35.5% |

家属"赶过去"是第一响应方式，但家属大多不在现场——这印证了"120 到达前的空白期"缺少专业响应力量的判断。

### 3.2 求助的最大障碍验证了产品核心设计

"老人在家突发意外时最大的困难"（多选）：

| 困难 | 占比 | 对应设计 |
| --- | --- | --- |
| **身边没有人可以帮忙** | **66.7%** | 敲击触发无需找人在场；AI 秒级响应 |
| 不会使用手机或求助设备 | 39.7% | 连敲三下即触发，零学习成本 |
| 突发时说不清地址或情况 | 33.3% | AI 语音引导收集 + 定位自动上报 |
| 担心费用太高 | 22.7% | 分级响应避免动辄叫 120 的高成本 |
| 120 到达时间太长 | 22.0% | 就近救护员分钟级上门 |

### 3.3 用户对方案的接受度高

| 态度项 | 认同率（同意+非常同意） |
| --- | --- |
| "敲击三下就能求助"对老人足够简单 | 75.2% 认为简单/非常简单 |
| 服务对老人安全很有帮助 | **88.7%** |
| 比直接打 120 更适合非致命紧急情况 | **87.2%** |
| 愿意尝试或让家中老人使用 | **89.4%** |

### 3.4 用户顾虑指向系统设计重点（多选）

| 顾虑 | 占比 | 系统对策 |
| --- | --- | --- |
| 响应速度不够快 | 58.9% | LBS 就近调度 + 在线救护员实时定位 |
| 救护员资质是否可靠 | 37.6% | 证书提交 + 平台审核（verify_status 状态机） |
| 系统出错（该来没来/不该来来了） | 34.0% | AI 分级置信度 + 家属确认兜底 + 全程留痕 |
| 费用是否合理 | 29.1% | 派单计酬透明化 |

### 3.5 付费意愿

约 39.7% 可接受单次 100 元以下（50 元以下 14.9%、50-100 元 24.8%），29.1% 可接受 100-200 元，29.8% 表示"视服务内容而定"。→ 计酬机制定价区间参考：**单次 50-150 元**，按服务分级浮动。

## 4. 需求 → 功能映射

| 编号 | 需求 | 功能模块 | 优先级 |
| --- | --- | --- | --- |
| F1 | 敲击触发求助 | 硬件端敲击检测 + 工单创建接口 | P0 |
| F2 | 说不清情况也能求助 | AI 语音引导收集 + 自动摘要分级 | P0 |
| F3 | 无人在场也能被响应 | 就近救护员派单与接单 | P0 |
| F4 | 家属知情 | 三方通知（家属/机构/120） | P0 |
| F5 | 资质可信 | 救护员证书审核 | P0 |
| F6 | 费用透明 | 派单计酬与评价（二期） | P1 |

## 5. 非功能需求

- **时效**：从触发到完成派单 ≤ 30 秒（接口 P95）；救护员呼叫响应目标分钟级；
- **可靠性**：分级错误有家属确认兜底；通知多通道冗余（微信订阅消息 + 短信）；
- **隐私**：病史/过敏史仅接单后可见；评价匿名；
- **适老化**：老人端零输入，全部自动上报。

## 6. 局限与后续调研计划

救护员侧（第 15-24 题）样本量为 0，尚未触达持证救护员群体。下一阶段将通过红十字会、医护院校渠道补充调研（目标 ≥30 份），重点验证：接单意愿、顾虑（责任纠纷/人身安全）、期望报酬与可接单时段，用于校准派单计酬与保障机制设计。
